A runnable reconstruction of the uploaded 9.67-second screen recording titled **Social Media Hover Effect — Using HTML & CSS**.

## What the video shows

A small pastel gradient tile sits in the middle of a light preview canvas. It contains a 3×3 grid of social platform icons. Hovering individual icons highlights them with their recognizable brand colors and a slight lift/scale effect. The video cycles through Instagram, X, Pinterest, LinkedIn, Discord, GitHub, Telegram and YouTube hover states, then returns to the pastel title tile.

The screen also displays two code panels labelled `index.html` and `style.css`. The source text is tiny and compressed, so the project recreates the visible structure and effect rather than claiming a verbatim extraction.

## Included interactions

- 3×3 social icon grid: Instagram, X, Pinterest, Dribbble, LinkedIn, Discord, GitHub, Telegram and YouTube.
- Brand-color hover effects.
- Lift, scale and shadow transitions.
- Keyboard focus styling.
- Live label showing the hovered social platform.
- Responsive layout.
- No libraries or build tools required.
